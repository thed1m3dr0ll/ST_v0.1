# Сайт «Стекляника»

Сайт на [Astro](https://astro.build): на выходе получаются обычные HTML-страницы,
которые можно разместить на любом хостинге.

## Запуск

Двойной щелчок по файлу **`Запустить сайт.bat`** в папке проекта. Откроется браузер
с адресом http://localhost:4321. Изменения в файлах видны сразу после сохранения.

Или вручную из папки `site`:

```bash
npm install      # один раз — установка зависимостей
npm run dev      # локальный сервер http://localhost:4321
npm run build    # сборка готового сайта в папку dist/
npm run preview  # просмотр собранной версии
```

Нужен Node.js 22+.

## Публикация

Сайт размещён на Netlify: **https://steklyanika.netlify.app** (аккаунт steklyanika.marketing@gmail.com).
Чтобы выложить изменения, выполните из папки `site`:

```bash
npm run deploy
```

Пока сайт черновой, он закрыт от поисковиков: `indexable: false` в `src/data/site.ts`
и файл `public/robots.txt`.

## Админка

Вакансии, объекты, контакты и сертификаты редактируются через админку: **http://localhost:4321/admin/**
(запускается вместе с сайтом через «Запустить сайт.bat»). Инструкция для админа —
`../АДМИНКА — как пользоваться.md`, для разработчика (как подключить админку на хостинге) — `ДЛЯ-РАЗРАБОТЧИКА.md`.

## Где что править

| Что поменять | Файл |
|---|---|
| **Вакансии** | админка → «Вакансии» (`src/content/vacancies/*.json`) |
| **Объекты** (карточки, фото, локация, выполненные работы) | админка → «Объекты» (`src/content/objects/<папка>/`) |
| **Телефон, почта, адрес, ВКонтакте, часы работы** | админка → «Настройки сайта» → «Контакты» (`src/content/contacts.json`) |
| **Сертификаты в карусели** (главная и «Партнерам») | админка → «Настройки сайта» → «Сертификаты» (`src/content/certificates.json`) |
| Цифры «6 лет / 100+ / 1000 м²…» | `src/data/site.ts` → `facts` |
| Пункты меню | `src/data/site.ts` → `nav` |
| Услуги | `src/data/services.ts` |
| Профильные системы на главной (список, характеристики) | `src/data/systems.ts`; картинки — из «для сайта/системы» через `node tools/prep-systems.cjs` → `src/assets/systems/catalog/` |
| Партнёры и сертификаты (страница «О компании») | `src/data/partners.ts` |
| Сертификат из PDF → картинка | положить в «для сайта/сертификаты», `python tools/prep-certificates.py` → `src/assets/company-certificates/`, затем выбрать в админке |
| Тексты секций главной | `src/components/home/*.astro` |
| Страницы | `src/pages/*.astro` |
| Цвета, шрифты, кнопки | `src/styles/global.css` (переменные в `:root`) |
| Отправка заявок (почта / CRM) | `src/scripts/leads.ts` |

Картинки лежат в `src/assets/`. Astro сам сжимает их в WebP нужного размера,
поэтому можно класть исходники до ~2–3 тыс. px по ширине.

## Структура

```
src/
  assets/       картинки (бренд, фото объектов, сертификаты)
  components/   блоки: шапка, подвал, форма заявки, карточки, секции
    home/       секции главной страницы (по Figma)
  content/      данные из админки (JSON): вакансии, объекты с фото, контакты, сертификаты
  data/         чтение данных и прочий контент: услуги, системы, партнёры, меню
  layouts/      общий шаблон страницы
  pages/        страницы сайта (адрес = имя файла)
  scripts/      заявки, маска телефона, фильтр
  styles/       общие стили и фирменные цвета
tools/          вспомогательные скрипты (подготовка картинок систем)
public/
  fonts/        Cera Pro и Pobeda (из брендбука, в формате woff2)
  images/       паттерн бренда
```

## Страницы

- `/` — главная (собрана по Figma-макету, 10 секций)
- `/about/` — о компании
- `/services/` — услуги (с фильтром)
- `/projects/` — объекты (с фильтром); описание объекта открывается во всплывающем окне, отдельных страниц нет
- `/partners/` — партнёры и сертификаты
- `/partners/developers/` — «Девелоперам» (открывается с карточки на «Партнерам»; объекты — все «Жилые комплексы» из админки)
- `/careers/` — вакансии
- `/contacts/` — контакты и переход на карточку в Яндекс Картах
- `/privacy/` — политика конфиденциальности (шаблон)
- `/careers/<вакансия>/` — страница вакансии (адрес — из названия)
- `/admin/` — админка (Decap CMS)
